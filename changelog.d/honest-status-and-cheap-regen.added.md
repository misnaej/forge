bump: minor

- **Pre-commit results now come from a command, not a summary.** New `forge-precommit --verdict` prints every enabled step's result for the code on disk and exits non-zero unless all passed on that exact tree. The pre-commit agent pastes it verbatim, re-runs the edited code's tests, closes with one full run, and a new hand-back hook (`require_fixer_verdict`) refuses a "success" report the verdict contradicts — so "all checks passed" can no longer be claimed over failing or stale checks.
- **A partial pre-commit run no longer erases the full result.** `forge-precommit --only …` now writes `precommit_only_timing.log`, so PR wrap-ups stop showing false ❌/❔ marks, and a test count from a different tree is shown as "no run at this tree" instead of an old number.
- **Generated docs regenerate only when needed.** The commit step skips `docs/api-digest.md` and `docs/cli-reference.md` when nothing they are built from changed (it says so per doc), using a small per-checkout record inside `.git/`; the CLI reference — which documents forge's own commands — now rebuilds only after a forge upgrade, and captures its `--help` pages in parallel when it does. This removes most of the ~10s that every commit paid in larger repos.
- **Disguised AI credit lines are refused.** The attribution check now ignores invisible zero-width characters and folds look-alike Unicode letters before matching.
- **Action:** none required. If your own scripts read `code_health/precommit_timing.log` after a `forge-precommit --only` run, read `code_health/precommit_only_timing.log` instead.
