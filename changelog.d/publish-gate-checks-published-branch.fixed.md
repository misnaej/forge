bump: minor
- **Publishing a pull request now checks the branch you are publishing, not whichever folder your session happens to sit in.** If you work in a second checkout, the check used to read your main folder, find a verification record describing different code, and refuse. Worse, when your main folder happened to hold a valid record of its own, the check passed while publishing a branch whose code nobody had verified. It opened in exactly the case it exists to close. It now finds the checkout holding the branch being published and checks that one, and refuses outright when no live checkout holds it rather than falling back to yours.
- **An ambiguous publish command is refused rather than guessed at.** Reading the branch out of the command text is not the same as parsing it the way the tool does, and where the two readings disagree the check would have examined a branch that was never going to be published. Two branch flags, or a branch-flag-shaped phrase inside the title beside a real one, are now refused outright with a message saying so.
- **Publishing from a second checkout no longer needs the skip switch.** That bypass existed only to work around this, and using it meant turning the check off rather than running it against the right code.
