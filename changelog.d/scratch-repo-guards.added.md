bump: minor

- **Agents get a sanctioned place to experiment, and the guards protect other people's unsaved work.** The new `forge-scratch-repo` command creates an isolated copy of the checkout (`snapshot`, optionally including uncommitted edits) or a small repo built from a list of commits (`build`), so reviewers, test advisors and test writers can try things without touching the shared working copy. FOUNDATION now says experiments happen only there and that a blocked operation is reported, never routed around; perf-optimizer uses the command instead of its own copy recipe. For agents, the guard hooks now also block: every `git stash` except `list` / `show`; restoring a file that holds uncommitted work (`git checkout [<ref>] -- <path>`, `git restore <path>`), checked against the live state of that file; forced branch switches (`git checkout -f`, `git switch -f` / `--discard-changes`); `git update-ref` and `git fast-import`; and git run from inline interpreter code (`python -c`, `node -e`, a heredoc script). Restoring a clean file, plain branch switching and conflict resolution (`--ours` / `--theirs`) are unaffected, and humans can still run any blocked form with `!`.
