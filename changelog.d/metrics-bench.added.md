`forge-metrics bench` compares forge versions on the same five small tasks (add a command, fix a bug, docs, refactor, review a diff), run by hand. `bench init --repo owner/name` fills an empty private GitHub repo with a sample project shipped in forge. `bench start <task>` puts a local clone of it on a fresh branch and prints the prompt to run in a normal session; `bench finish` records tokens, time, review rounds, lines changed and outcome facts (tests, task checks, pre-commit verdict, PR opened) with the forge version installed in the clone, then closes the PR and deletes the branch. `bench report` shows versions side by side per task. Each run costs about one PR's worth of tokens.
