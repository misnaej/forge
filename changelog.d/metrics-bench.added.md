`forge-metrics bench` runs the same five small tasks (add a command, fix a bug, docs, refactor, review a diff) against a chosen forge version, so versions can be compared on equal work. `bench init --repo owner/name` fills an empty private GitHub repo with a sample project shipped in forge; `bench run --version vX` takes each task to a posted PR wrap-up in a throwaway copy with that version installed, records tokens, time, review rounds, lines changed and outcome facts in the per-machine database, then closes the PR and cleans up; `bench report` shows versions side by side per task. Runs are manual and costly: a full set spends about as many tokens as ten PRs.
