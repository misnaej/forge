bump: patch
- Agents can no longer move a git ref by asking GitHub to do it. A `gh api` call against the `git/refs` endpoints moves a branch or tag on GitHub's side with no local git and no push, so neither the force-push guard (which watched for `git push`) nor the protected-branch guard (which watched for a local commit or push) ever saw it — including a call that force-moved the base branch. `block_force_push` now refuses any such call that carries a method or body flag, for any ref including tags, and the `updateRef` mutation carrying a force.
- The guard reads no flag values, because a parser that did disagreed with the GitHub CLI's own on every one of these spellings and let a force through: an attached `-fforce=true`, a short cluster like `-iXPATCH`, a repeated `force=` where the last one wins, a stray `force:false` elsewhere in the command. A ref write that cannot be told apart from a force is now treated as one.
- Separately, every guard that locates a command in a shell line now treats a closing `)` as the start of the next command. A `case` arm begins its command there, so wrapping a command in one hid it from all of them at once: `case x in x) git push -f origin main ;; esac` was allowed while the plain form was blocked, and the same trick slipped past the guards on destructive git commands, pull-request merges, rebases, raw `ruff`, `--no-verify` and deletion of the handoff note. All of those are now refused in that form too.
- The same gap let one allowed command mask another. The guard that keeps the pre-commit fixer to its own small set of commands split them without treating `)` as a boundary, so `X=$(cd /tmp) ls -la` passed on the strength of the `cd` while bash ran the `ls`. It is refused now.
- Reading refs still works, and so does every endpoint outside `git/refs`, writes included — a comment whose body happens to mention `git/refs` is not refused. The cost is that a non-force ref update, which could only fast-forward, now needs a person to run it; `forge-update-branch` remains the way to sync a branch.
- This is a tripwire, not a sandbox: a command that hides the endpoint or the flags from the shell's text — in a variable, a brace expansion, a glob — still gets through, as do other endpoints that write a branch and clients other than the GitHub CLI. The blocked and allowed forms, and the gaps known today, are listed in `forge-docs/git-safety.md`.
