`forge-metrics publish --repo OWNER/NAME` pushes a public metrics page (`index.html` plus `metrics.json`) to a dedicated public repo served by GitHub Pages. While publishing is an experiment, only forge's maintainer may publish, and only to a repo under their own account. The public version has no dates, no names, no PR keys and no repo ids: forge's own repo shows as "forge" and every other repo as one "external" series, with PRs grouped by forge version in a fixed scrambled order, so an unchanged database pushes nothing. Before writing anything it checks that the repo is public, that you administer it, and that it holds only files publish writes; it never force-pushes. It prints the page address, and the one-time command to turn Pages on when Pages is off. `--dry-run DIR` writes the two files locally without any network call.
