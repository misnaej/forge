`forge-metrics publish --repo OWNER/NAME` pushes a public metrics page (`index.html` plus `metrics.json`) to a dedicated public repo served by GitHub Pages. The public version has no dates, no names and no PR keys: repos show as short random ids, and PRs are grouped by forge version and shuffled. Before writing anything it checks that the repo is public, that you administer it, and that it holds only files publish writes; it never force-pushes. It prints the page address, and the one-time command to turn Pages on when Pages is off. `--dry-run DIR` writes the two files locally without any network call.
