bump: minor

Minor, not patch: the `block_no_verify` Claude Code hook gains refusals agents will hit, and `forge-doctor` gains a check.

- Agents can no longer move or override where git looks for hooks. git finds the pre-commit hook through `core.hooksPath`; pointed anywhere else, even for one command, a commit runs no forge gate and succeeds as if it had passed. `block_no_verify` now refuses, for every agent including the commit agent: a `git config` write of that key in any scope or file (set, `--add`, `--replace-all`, `--unset`, `--unset-all`, the `set` / `unset` subcommands), removing or renaming the `core` section, `-c core.hooksPath=…` or `--config-env=core.hooksPath=…` on any git command, and `GIT_CONFIG_KEY_<n>` / `GIT_CONFIG_PARAMETERS` assignments naming the key. The key is matched in any letter case, as git reads it. Reading it (`git config --get core.hooksPath`) stays allowed. The refusal points at `install-forge-githooks`.
- In a repo that tracks forge's `.githooks/pre-commit`, an agent's commit, merge or pull is refused when the hooks folder git would actually use has no executable `pre-commit` — the state in which every commit goes through unchecked. A repo on another hook manager (one not tracking that file) is never refused, and `git merge --abort` / `--quit` are not checked.
- `forge-doctor` reports, as an advisory, the hooks folder git resolves in the current checkout, the configured `core.hooksPath` (or git's default), and whether a runnable `pre-commit` sits there.
- Documented: a merge git completes without conflicts commits through `pre-merge-commit`, which forge does not install, so that commit runs no local gate — by design. CI runs `forge-precommit` on every PR and push, the next commit's gate checks the merged state, and tree-stamped check logs already read as stale after the merge. FOUNDATION §2's sync ladder and `docs/customizing-precommit.md` say so.
- Internal: one `forge.git_utils.git_path` helper resolves paths inside the git dir (`git rev-parse --git-path`) for every caller that used to inline it.
