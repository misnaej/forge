- New `forge-pr-watch` CLI owns the background PR monitor lifecycle: `start --pr N` spawns a bounded poll loop (declared `--bound`, default 30 min) after an arming check verifies all five signals are parseable (gh present, auth ok, repo resolved, pr-view JSON, comments JSON) — a blind start is a loud non-zero exit, never silent. `list` reads the registry (`.plan/pr_monitors.json`, gitignored); `stop --pr N` verifies the process command line before signalling, so a stale pid is reported, never killed. Self-skips in CI.
- `forge-pr-plan --freshness` gains a `--repo owner/repo` flag (works outside a checkout) and a structured `cause` field in its JSON verdict (`no-gh` / `no-repo` / `no-pr-view` / `no-head` / `no-verified-at` / `ok`) so a blind watch is distinguishable from a quiet one; the `fresh: null` skip contract is unchanged.
