bump: minor
- **Forge no longer implies it can tell you which version of itself your session is running — because it cannot.** A Claude Code session picks up its copy of forge's agents, skills and hooks when it starts, and keeps that copy until you restart it. Update forge mid-session and the files on disk change while the session carries on with the old ones. The usual sign is a missing agent, which is loud and obvious; the common case is quiet — an older skill that still works, so the session follows instructions that were right one release ago and nothing looks wrong. Meanwhile every version check reports healthy, because they all read the disk and none of them can see what your session loaded. Three things change: restarting is now stated as the last required step of any upgrade that moved the plugin rather than a note at the end, and an assistant that performs such an upgrade stops and asks you to restart instead of continuing on the old copy; the version-alignment line now says which surfaces it compared and that the plugin is not one of them, so it stops reading as a verdict on your whole install; and a report filed back to forge now records that the running version is undetermined instead of naming one it cannot know. **None of this is enforced by a check, and that is stated plainly** — nothing can confirm you restarted.
