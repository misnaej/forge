- **Background PR monitors, the `/code-review` offer and `/plan-batch` were switched off in every agent session, and now run.** Each was told to stand down when nobody was around to receive it, but the test used for "nobody is around" was whether the command had a terminal attached. An agent never has one — it runs everything as a subprocess — so the answer was always "nobody", in exactly the sessions these features were built for. Monitors therefore never watched a pull request for review comments, conflicts, CI failures or a stale wrap-up; the second-opinion review was never offered; batch drafting always stopped before it started. Presence is now decided by whether the run is genuine CI, which is what the question was always asking. **You will see activity you have not seen before:** a background monitor per open PR, and an offer to run a billed second-opinion review during PR finalization, which you can decline. Nothing new runs in CI.
