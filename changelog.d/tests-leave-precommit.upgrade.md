bump: major

- Pre-commit no longer runs tests, and cannot be configured to. The opt-in `smart_test` pre-commit step is gone, with the four settings that only existed to drive it: `precommit_depth`, `blocking`, `full_run_max_age_hours` and `cadence_mode`. Commits never wait for a test run.
- The periodic truly-all run that makes lifecycle deselection safe is now CI's job, not a tracked timestamp's. The `.forge-full-run` stamp is deleted along with the code that read and wrote it. In forge's own repo that stamp had sat 86 days stale against a 48-hour guarantee, because its only reader was a step nobody had enabled — while CI was in fact running the whole suite on every pull request.
- Adopting this in a consumer repo: delete `precommit_depth`, `blocking`, `full_run_max_age_hours` and `cadence_mode` from `[tool.forge.smart_test]`, and delete the `.forge-full-run` file if your repo tracks one. Then make sure CI runs the full suite — if it already does on every pull request, you have the guarantee and there is nothing more to add; otherwise add one job on default-branch pushes running `forge-smart-test --depth full --all-tests`, with an optional `schedule:` trigger for quiet periods. Ready-made jobs are in `forge-docs/ci-recipe.md`. Leaving a removed key in place is harmless but ignored; leaving `"smart_test"` in `[tool.forge.precommit].enable` is a loud error naming the unknown step.
- `forge-smart-test`, `/forge-smart-test`, depth-tier selection and lifecycle deselection are unchanged for local and CI use.
- Rules for what belongs in `FOUNDATION.md` are now written down in `forge-docs/foundation-compaction.md`: a passage earns its place only if it binds every repo whatever features they enabled, applies to more than one role, and would be acted on wrongly before anyone thought to open a pointer. Test-authoring standards move to the agents that apply them, cutting 292 words that every session carried for a scheme most repos never switch on.
- Word budgets are ceilings, not targets, and every `forge-docs/` page now has its own, so moving detail out of FOUNDATION reduces it instead of hiding it somewhere unmeasured.
