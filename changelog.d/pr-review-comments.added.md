bump: minor

- New `forge-pr-review-comments` CLI. `list --pr N` prints every review comment on a PR from every page, one JSON object per line; `unreplied --pr N` exits 1 printing the ids of top-level comments nobody has replied to, 0 when every one has a reply, and 2 when GitHub could not answer or returned a page it could not parse — never read as "none unreplied". `forge:pr-manager` and `/pr-comments` now read review comments through it, so comments past the 30th are no longer missed. The listing itself is `forge.gh_comments.list_review_comments`.
- Every GitHub listing in the shipped agents and skills now reads the whole list: `gh issue list` / `gh pr list` / `gh search` pass `--limit 1000` (open PRs in `forge:issue-triage`, a user's PRs and issues in `forge:weekly-summary`, open performance issues in `/perf`, related issues in `forge:pr-manager`). Forge's own tests fail when a shipped agent or skill adds an unbounded listing.
- `forge:pr-manager` lists every commit, merge and push its run caused — its own or a delegate's, with SHA, files and whether it was pushed — and quotes every guard refusal with the refused command. A refusal ends that step: it reports and asks instead of reshaping the command to the same effect.
