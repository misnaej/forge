bump: minor
`forge-metrics` now keeps one database per machine instead of one per repo, and that database holds no names: no repo name, PR number, title, branch or file name. Each repo is a random id and each PR a hash of that id and its number; the only file linking an id to a repo is a local `repo-ids.json` next to the database, which reports and exports never print. The PR's main-session model is now recorded, and agent types forge and Claude Code do not ship are stored as `other`. Reports label PRs by merge day, short repo id and ordinal, and accept `--repo` to narrow to one repo; `export` writes the stored rows as they are. Existing per-repo databases are imported without their names on first run and then deleted.
