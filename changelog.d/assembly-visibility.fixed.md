- **A failed assembly run now files itself as an issue, and runs daily while that is proven.** The scheduled `assemble-release` workflow is what advances `.claude-plugin/plugin.json`, and Claude Code keys its plugin cache on that version — so when a scheduled run failed, the manifest stayed frozen at its last assembled version across fifteen subsequent tags, and no consumer could reach the guard hardening those tags shipped. Nothing reported the failure: GitHub mails only whoever last touched the cron, and the backlog everyone reads showed nothing. The workflow's failure path now opens an issue naming the run and the consequence, or comments on the existing one rather than filing a duplicate. The cadence moves from weekly to daily while the fix is observed, then to Mondays/Wednesdays/Fridays — a weekly schedule turns one silent failure into a week of frozen plugin distribution.
