bump: minor
`forge-metrics bench finish` now also commits the results to the benchmark sandbox repo, so it no longer matters which machine runs the benchmark: `results/benchmarks.json` holds every run (keyed by run id, so sharing a run again never duplicates it and other machines' runs are kept) and `results/index.html` shows the report. The commit is made on the clone's `main` (a clone with uncommitted changes is refused, nothing discarded), never on the run's branch; if another machine pushed first the results are merged and pushed again, and after three tries they stay local until the next `finish`. `forge-metrics bench report --from-sandbox` shows every machine's runs.
