bump: minor
- **The light and delta review paths work again.** `light-code` could never fire: any added file disqualified it, and forge's own gate compels every PR to add exactly one `changelog.d/` fragment — so the path had fired once in the repo's history, on the PR that introduced it. Fragments are now exempt, because the added-file rule exists so the prior-art gate sees new source files and a fragment poses it no question. `delta` was defeated by any base merge, which counted all of the base's incoming lines against a threshold meant for the branch's own work; it now holds whenever the branch's own changed paths are identical to the verified tree, regardless of how far the base moved. `agents/pr-manager.md` and the `/pr` mode table carry the same qualifier, so the classifier and the prose can no longer disagree.
- **A consumer can finally see a stale plugin cache.** `plugin_cache_status` resolved the manifest from the repo being checked, so on any consumer — which ships no plugin of its own — it returned `no-manifest` and both `forge-doctor` and `plugin_sync` went silent on the entire population that suffers the problem. It now falls back to comparing the active cache slot's hooks against the marketplace clone at the pinned ref, reporting which hooks never load and a remedy that can actually converge. Comparing content rather than the declared version is deliberate: under tag-per-merge with assembly later, no tagged tree's manifest equals its own tag, so two different trees can occupy one cache slot and the version string identifies nothing. The reader had no direct tests; it has ten now.
- **`forge:git-commit-push` may no longer author a changelog fragment.** Observed: told to stage two files, it committed three, inventing a fragment and with it the released version level — then the one-fragment-per-PR gate refuses the correct one, so the only way out is a banned flag. The gate's own message was the cause; it named no owner and handed the reader a complete authoring recipe, at a moment when the reader is the commit agent. The message now names the author and the moment. The agent gains an explicit report-only contract for `changelog.d/`, a stop rule covering *creating* a file to pass a gate rather than only destroying one, a `## Failure states` section, `forge:`-prefixed agent names that actually resolve, and the tier its irreversibility warrants.
- **One rule now covers every guard bypass** (FOUNDATION §2): only on the user's word, confirmed once, authorised by an act an agent cannot perform, recorded, and owing follow-up. A bare environment variable an agent could set for itself is a suggestion, not a gate.
