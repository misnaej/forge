bump: patch
- **A pull-request wrap-up no longer drops a reviewer's findings when the review passed.** Reviews normally open with "PASS" and then list what was found anyway — nothing blocking, but worth knowing. The wrap-up treated that opening word as meaning there was nothing to report and kept only that line, discarding everything after it. The findings vanished from the one document whose purpose is recording them, and nothing indicated anything had been removed. A review that carries findings now always reaches the wrap-up, whatever word it opens with.
- **Check output saved for later reading is no longer littered with colour codes.** Tools colour their output when the surrounding environment asks them to, and that request overrides the usual "this is a file, not a screen" detection — so saved output could arrive as `^[[32m33 passed^[[0m` and be quoted that way into a pull request, wrapping the very number a reader was checking in garbage. Saved output is now stripped of colour codes as it is written.
