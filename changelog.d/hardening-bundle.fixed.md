bump: minor
- **`forge:perf-optimizer` is an advisor with no `Write`/`Edit`.** It no longer edits the repo tree while benchmarking: every strategy is applied to a scratch copy under `/tmp/perf_<target>_src/` and the winner is delivered as a patch the main agent applies. A consumer wrapper that relied on the agent editing files in place must apply the reported patch itself. `forge-audit-agents` now checks advisor agents (`ADVISOR_AGENT_NAMES`) for mutating tools, so this cannot regress.
- **`install-forge-readme-badges` picks the CI workflow deterministically** — `ci.yml`/`ci.yaml` by name, else the workflow whose `on:` includes `pull_request`. With neither, the README's existing CI badge is kept and a warning logged instead of the badge being re-pointed at the alphabetically first workflow.
