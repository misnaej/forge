bump: major

- **The session handoff note becomes a live status panel plus a short written section.** `.plan/CONTINUATION.md` used to grow without limit (one consumer's had 931 lines) and was written only after successful commits, so a stuck commit loop left no trace. It now opens with a fixed-size status panel that `forge-continuation state` rewrites on every commit attempt — blocked ones included — at `/pr` wrap-up, and just before Claude Code compacts the conversation: branch, commits ahead and behind, unpushed commits, staged and unstaged files, pending changelog fragments, the last commit attempt and the open PR's state. Below it sits the agent's written section, capped at `[tool.forge.continuation].judgment_max_lines` (default 60; `forge-continuation check` reports usage). The activity ledger, daily digest and archive are gone — git and GitHub hold the history — and an existing note is migrated on first write without losing its summary. A new SessionStart hook reads the note into context as quoted data, and FOUNDATION §10 now tells agents to hand off and offer `/clear` when context runs low instead of letting compaction lose it. **Breaking:** the CLI is renamed from `forge-continuation-append` to `forge-continuation`, its `--commit` / `--pr` / `--merge` / `--rotate` options are removed, and the `max_recent_entries` / `max_recent_age_days` config keys are replaced by `judgment_max_lines`; update any permission rule or script that names the old CLI.
