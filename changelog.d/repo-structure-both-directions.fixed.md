bump: patch

- **The `REPO_STRUCTURE.md` check is stricter, and may fail after you upgrade.** That failure is real drift it used to miss. To fix it, edit `REPO_STRUCTURE.md`: (1) replace the text between the title and the first section with the sentence the check prints under HOW TO FIX, pasted exactly; (2) add a `- <name>: <description>` bullet for every file or folder it reports as unlisted, or add `<!-- summary -->` to the end of the heading of a section that describes its folder in prose instead of listing it; (3) correct or remove every stale name it reports. A section heading with no folder path may now hold only file and folder bullets, so move or delete any prose there.
- **Every folder with its own heading must now list everything in it.** This covers every file and subfolder git tracks or would track, except hidden files, `__init__.py` and `conftest.py`. Before, only the top level was checked, plus sections that opted in with `<!-- exhaustive -->`. That marker is now the default, and a leftover one is a harmless comment.
- **The map's bullets are all read now.** Before, the check saw only `.py` file bullets, so deleting a listed agent, skill or doc file still passed. Sibling folder bullets no longer nest under one another.
- **Paths named in descriptions must exist.** File names and folders in backticks are checked against the folder they are described under, then the repository root. Command names, config keys and patterns are not checked.
- **The summary reports each direction separately.** On a pass as well as on a failure, it prints listed-but-missing, on-disk-but-unlisted, stale names, opening and prose problems, and which folders were checked in full. The old "Paths checked" count is gone, because it only counted what the map mentioned.
