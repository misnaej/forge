bump: minor
- **A release can be committed again.** The check that warns when the editor's cached copy of forge is older than the project compares it against the version file — and writing that file is exactly what a release does. So every release was refused as stale, and the suggested remedy could not help: it re-reads the same version, which nothing has published yet, and reports no change. The check now warns instead of refusing. A genuinely cold cache is still called out; it just no longer blocks the one commit that would fix it.
- **The emergency escape now reaches the checks that were trapping it.** Forge has a deliberate way out when something must ship and the usual verification cannot run: a person arms it, it announces itself on a public issue before it exists, and it works once before expiring. It left every commit-time check enforced, reasoning that the build re-runs them so skipping locally would only move the failure. Two of those checks — the ones comparing your local install and cached copy against the project — already stand aside in the build, so there was nothing downstream to move a failure to. Leaving them enforced protected nothing and blocked exactly the situation the escape exists for. They now stand aside too. Every safety guard is untouched and still cannot be bypassed.
