bump: minor
- **Upgrading to a version the release notes never mention is now refused.** A version number is created every time work merges, but the release notes are written separately, when a release is assembled. Between those two moments a version exists that nothing documents — and upgrading to it printed an "Upgrade notes" section that simply stopped early, with no sign anything was missing, so any step you were expected to take went unseen. Such a version is no longer adoptable: the upgrade installs it and may already have pointed your pin at it, but goes no further — naming the newest version that is documented, and telling you to point the pin back at that one or ask for a release covering the one you wanted. Pinning a branch instead of a version is unaffected — that is a deliberate choice to track undocumented code.
- **A stale Claude Code plugin cache now says so in the first word.** When your plugin cache does not carry the content you pinned, the advisory now opens with "STALE PLUGIN" instead of burying the problem among routine notes.
