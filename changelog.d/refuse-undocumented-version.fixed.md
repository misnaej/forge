bump: minor
- **Upgrading to a version the release notes never mention is now refused.** A version number is created every time work merges, but the release notes are written separately, when a release is assembled. Between those two moments a version exists that nothing documents — and upgrading to it printed an "Upgrade notes" section that simply stopped early, with no sign anything was missing, so any step you were expected to take went unseen. Such a version is no longer adoptable: the upgrade stops before writing anything into your repository, names the newest version that is documented, and tells you to take that one or ask for a release covering the one you wanted. Pinning a branch instead of a version is unaffected — that is a deliberate choice to track undocumented code. Forge also now says "STALE PLUGIN" when your plugin cache does not carry the content you pinned, instead of burying it among routine notes.
